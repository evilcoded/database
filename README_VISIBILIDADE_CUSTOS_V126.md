# V126 — Visibilidade das revisões de custos

Corrige a seção que desaparecia quando não havia projeções de custos nos cenários filtrados. A seção passa a informar separadamente ausência de ligação no servidor, ausência de cenários ou ausência de resultados na pesquisa. Não certifica custos e não altera cálculos, modelos ou dados financeiros.

Instala somente o JavaScript do painel e a versão de cache no template. Requer os arquivos exatos do V125; divergências são preservadas e interrompem a instalação. Inclui backup e reinício opcional com o mecanismo existente.

Validação: estados com custo conhecido, desconhecido, filtros, ausência de cenários e ausência de ligação; renderização do patrimônio preservada. Instalador verificado para repetição, divergência e preservação de modelos e ledger com dados sintéticos.
